<h1>Here are the source files for Sanzhar Abdrakhim's URIS 2023 cohort project</h1>
<p>Important note about installation and setup of the project.</p>
<p>Install mamba-ssm of version 2.2.4 and causal-conv1d 1.5.0.post8</p>
<p>Use commands:</p>
<p>pip install causal-conv1d==1.5.0.post8 --no-build-isolation</p>
<p>pip install mamba-ssm==2.2.4 --no-build-isolation</p>
<h1> How to navigate? </h1>
<p><b>notebook.ipynb</b> is the main code. All of the training and model code is here. </p>
<p></p><b>ensembly.ipynb</b> is the code for ensembling models. </p>
<p><b>convertNote.sh</b> is shell code to start program in offline mode.</p>
